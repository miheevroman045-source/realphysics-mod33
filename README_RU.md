# HOMELANDER POWERS — мод для Minecraft Java 1.21.1 (Fabric)

Большой фанатский мод со способностями Хоумлендера. **Это исходники проекта, не собранный JAR**.
Можно собрать в GitHub Actions, как в предыдущем моде RealPhysics.

## Что уже реализовано

1. **Костюм из 4 предметов**: маска, нагрудник, поножи, сапоги. Собственные текстуры и крафты.
2. **Лазеры из глаз**: двойной красный луч на 48 блоков, обжигает и наносит урон. Не прожигает блоки.
3. **Управляемый полёт**: V включить/выключить, затем дважды пробел для взлёта.
4. **Ударная волна**: урон и отбрасывание мобов вокруг тебя.
5. **Скоростной рывок**: быстрое перемещение по направлению взгляда.
6. **Суперудар**: 26 урона и мощное отбрасывание цели перед тобой.
7. **Героическое приземление**: падение с мощным ударом по площади.
8. **Пассивные силы**: сопротивление, сила, скорость, огнестойкость, регенерация, отсутствие урона от падения.
9. **Compound V**: сыворотка, дающая силы на три минуты даже без костюма.
10. **Босс Homelander**: особо сильный зомби в костюме, 200 HP, выпускает лазер примерно раз в 5 секунд в находящихся рядом игроков (босс использует обычную зомби-анимацию).
11. **Крафты**, русские и английские названия, отдельные клавиши и команды.
12. **Мультиплеер**: у всех игроков должен быть клиентский мод, а у сервера — тот же мод, Fabric Loader и Fabric API.

## Клавиши

| Клавиша | Действие | Перезарядка |
|:--:|---|---:|
| **H** | Лазеры из глаз | 0,9 секунды |
| **V** | Вкл./выкл. полёт | нет |
| **G** | Ударная волна | 4,5 секунды |
| **R** | Скоростной рывок | 1,75 секунды |
| **B** | Суперудар по мобу перед игроком | 1,3 секунды |
| **N** | Геройское приземление в воздухе | 5 секунд |

Клавиши можно менять в Minecraft → Настройки → Управление → Назначение клавиш.

## Команды

- `/homelander help` — помощь
- `/homelander kit` — полный комплект и сыворотка (требуются читы/OP)
- `/homelander boss` — призыв босса (требуются читы/OP)
- `/homelander laser`, `/homelander fly`, `/homelander clap`, `/homelander dash`, `/homelander punch`, `/homelander land` — запускают те же действия, что и клавиши. Нужны костюм или сыворотка.

В творческом режиме предметы доступны во вкладке «Бой» / Combat.

## Сборка через GitHub Actions (без установки Gradle на ПК)

1. Распакуй ZIP на компьютер.
2. Создай **пустой новый репозиторий** GitHub (например, `homelander-mod`).
3. Нажми `uploading an existing file` и загрузи **содержимое распакованной папки**, а не папку целиком. Должны быть видны `.github`, `src`, `build.gradle`, `settings.gradle`.
4. `Commit changes` → `Actions` → `Build Homelander Minecraft Mod`.
5. После зелёной галочки зайди в успешный запуск и скачай `Homelander-Powers-1.21.1` из `Artifacts`.
6. Распакуй скачанный ZIP и положи `homelander-powers-1.0.0.jar` в `.minecraft/mods` вместе с Fabric API. Запускай профиль Fabric Minecraft 1.21.1.

**Если красная галочка:** открой красную сборку → `build` → шаг `Compile and remap Minecraft mod`, скопируй/пришли лог ошибки. Проект не протестирован реальным запуском Minecraft в этой среде.

## Технические параметры

- Minecraft **1.21.1**, Fabric Loader **0.16.14**, Fabric API **0.116.17+1.21.1**.
- Java **21**, Yarn mappings **1.21.1+build.3**, Gradle **8.9**, Loom **1.7.4**.
- Мод отдельно от RealPhysics, оба проекта можно попробовать использовать одновременно.
- Урон и кулдауны считаются **на сервере**. Игрок не может указать произвольную цель или урон через пакет.
- Полёт отключается при снятии комплекта/истечении Compound V; под действием эффектов бонусы обновляются раз в 2 секунды.
- Удары не разрушают блоки, чтобы случайно не уничтожить постройки.
